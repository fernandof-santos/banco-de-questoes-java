Este projeto foi desenvolvido para praticar os fundamentos da linguagem Java através da criação de um sistema de banco de questões executado no console.

O projeto também funciona como uma ferramenta de estudo, permitindo cadastrar questões e utilizá-las posteriormente em um simulado para revisar conteúdos e praticar a linguagem Java.

---

## 📚 Funcionalidades

- Cadastrar questões
- Listar questões cadastradas
- Atualizar questões existentes
- Remover questões
- Realizar um simulado
- Contabilizar acertos e erros
- Validar respostas das alternativas
- Validar números das questões
- Tratar entradas inválidas no menu

---

## 🛠 Tecnologias

- Java

- GitHub

## 🧠 Conceitos Praticados

- Variáveis e tipos de dados
- Estruturas condicionais (`if` / `else`)
- Estruturas de repetição (`while` / `for`)
- `switch` / `case`
- `ArrayList`
- Índices de listas
- Métodos `add()`, `get()`, `set()` e `remove()`
- Entrada de dados com `Scanner`
- Validação de dados
- Tratamento de exceções com `try` / `catch`
- `InputMismatchException`
- CRUD (Create, Read, Update e Delete)

---

## 🎯 Objetivo

Este projeto foi desenvolvido como uma forma de consolidar os fundamentos da linguagem Java antes de iniciar o estudo de Programação Orientada a Objetos (POO).

Durante o desenvolvimento, foram praticados conceitos de lógica de programação, estruturas de repetição e decisão, manipulação de listas, entrada e validação de dados, operações de CRUD e tratamento de exceções.

Além de servir como prática de programação, o sistema também pode ser utilizado para cadastrar questões e realizar simulados, permitindo revisar conteúdos estudados.
